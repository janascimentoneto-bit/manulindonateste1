☁️ Sincronizar entre aparelhos
Usa um banco de dados gratuito (Firebase) pra manter celular e tablet com os mesmos dados automaticamente. Configura uma vez em cada aparelho, usando o mesmo código.

1. Crie um projeto grátis em console.firebase.google.com
2. Ative "Realtime Database" (modo teste)
3. Em Configurações do projeto → seus apps → Web, copie o objeto de configuração e cole abaixo
4. Escolha um código de sincronização (uma senha só sua, ex: uma frase longa) e use o mesmo código nos dois aparelhos
